# Grape leaf disease detection system based on deep learning YOLOv10

## Body

Based on the deep learning YOLOv10, a grape leaf disease detection system (YOLOv10+YOLO dataset + UI interface + Python project source code + model) has been developed. This project utilizes the YOLOv10 (You Only Look Once version 10) object detection algorithm to develop an efficient grape leaf disease detection system. The system can automatically detect diseased areas in grape leaf images and classify diseases (such as black rot, grapevine wilt, healthy leaves), providing planters with disease early warning and prevention and treatment suggestions.
